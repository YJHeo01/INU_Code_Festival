# INU_Code_Festival

<ul>
  <li>인천대학교 교내 알고리즘 경진대회, INU 코드페스티벌에서 제가 출제한 문제들에 대한 정보를 저장하는 레포지토리입니다.</li>
  <li>각 연도별로 폴더를 분류하였고, 연도 폴더 내에는 해당 연도에 제가 출제한 문제들로 폴더가 구성되어 있습니다.</li>
  <li>문제 폴더 내에 있는 폴더는 총 4개가 존재합니다..<br>
    <ul>
      <li> Generator : 문제의 테스트 데이터를 랜덤으로 생성해주는 generator 파일들이 있습니다.</li>
      <li> Validator : generator로 생성한 랜점 테스트 데이터, 일부 풀이를 저격하기 위해 직접 제작한 테스트 데이터가 문제의 입출력 조건에 위배되지 않는지 체크해주는 validator 파일이 있습니다.</li>
      <li> Solution : 출제자가 의도한 풀이가 있습니다.</li>
      <li> TestCase : 대회에서 사용된 테스트 케이스 모음집입니다.</li>
    </ul>
    <li> generator, validator는 codeforces polygon의 testlib.h 헤더파일을 이용하며, 이에 대해 더 자세히 알고 싶은 분은 <a href="https://github.com/MikeMirzayanov/testlib">링크</a>를 참조하시길 바랍니다.</li>
  </li>
  <li> 문제에 대해 궁금한 점이 있으시거나, INU 코드 페스티벌 출제에 관심 있으신 분은 sk14cj@inu.ac.kr로 메일 부탁드립니다.</li>
</ul>
